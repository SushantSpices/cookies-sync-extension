1. Clone the repo.
2. goto chrome://extensions/
3. Toggle developer mode to on
4. Click on "Load Unpacked"
5. Select the cloned folder itself
6. The extension should appear where you have all the installed extensions.
7. Goto UAT login screen: https://uat-tenant.providhy.com/ and login to the system.
8. After login Go to your extensions list and click on the "cookie sync extension"
9. Now open your localhost:3000, you should be logged in the the localhost with the same credentials as in the UAT.
